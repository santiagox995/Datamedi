# Datamedi

## Descripción

Datamedi es una plataforma web diseñada para médicos independientes que permite administrar pacientes, historias clínicas, familiares, citas y documentos médicos desde un único sistema seguro.

## Problema

Muchos médicos independientes almacenan la información de sus pacientes en archivos físicos, hojas de cálculo o aplicaciones que no están adaptadas a sus necesidades.

## Solución

Crear una plataforma web intuitiva donde el médico pueda gestionar toda la información clínica de sus pacientes desde cualquier dispositivo.

## Objetivo

Construir una aplicación moderna utilizando ASP.NET Core, React y PostgreSQL que sirva como herramienta profesional y como proyecto de aprendizaje.
