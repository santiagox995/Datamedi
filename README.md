# **Datamedi**
## **Objetivo** 
Desarrollar una aplicación web que permita a médicos independientes gestionar de manera segura y eficiente la información de sus pacientes, facilitando el registro de datos personales, historial clínico, antecedentes médicos, familiares, citas y documentos asociados, con el fin de optimizar la administración de la consulta, mejorar el acceso a la información clínica y brindar una atención médica más organizada y de calidad.

### **Objetivos Específicos**

* Diseñar un sistema de autenticación que permita a cada médico acceder de forma segura a su información.
* Implementar un módulo para el registro, consulta, actualización y eliminación de pacientes.
* Desarrollar un módulo para almacenar el historial clínico de cada paciente, incluyendo diagnósticos, tratamientos y observaciones.
* Permitir el registro de familiares y antecedentes médicos relevantes para cada paciente.
* Implementar un sistema de gestión de citas médicas y seguimiento de consultas.
* Facilitar la carga y consulta de documentos médicos, como fórmulas.
* Diseñar una interfaz web intuitiva que facilite el uso de la plataforma por parte de médicos independientes.
